# online-retail-sql-analysis
PROJECT OVERVIEW:
This project analyzes an Online Retail dataset using MySQL to explore sales performance, customer behavior, order patterns, and purchasing trends.
The project demonstrates how SQL can be used to clean, explore, aggregate, and analyze real-world transactional data.

The dataset contains approximately 541,000 transaction records.

SQL ANALYSIS:
The project includes multiple SQL analysis files covering:
Data exploration
Filtering and sorting
Aggregations
GROUP BY and HAVING
Subqueries
Common Table Expressions (CTEs)
Joins
Window functions
Customer analysis
Sales and order analysis

PURPOSE:
This project was created as a practical SQL portfolio project to demonstrate the ability to work with a large transactional dataset and apply SQL techniques to real-world business analysis.
